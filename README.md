# Noyau Affamé

Un jeu de construction d'usine en pixel art : faites circuler du bois, transformez-le et nourrissez le noyau.

## Télécharger pour Windows

[**Télécharger Noyau Affamé pour Windows**](https://github.com/thimeobocquier/noyau-affame-telechargements/releases/latest/download/Noyau-Affame-Windows.zip)

Ce lien lance le téléchargement de l'archive du jeu, sans compte GitHub. Vous pouvez le partager sur Discord.

Décompressez toute l'archive, puis ouvrez **Noyau Affame.exe** dans le dossier extrait. Gardez tous les fichiers du dossier ensemble.

## Mises à jour automatiques à partir de la v19

Si vous avez la v18, téléchargez la v19 une fois. Ensuite, les nouvelles versions du jeu se téléchargent en arrière-plan et s'appliquent au prochain lancement, avec vos sauvegardes. La partie continue pendant le téléchargement. Sans Internet, le jeu reste disponible. Les fichiers sont vérifiés ; une version qui échoue au démarrage est remplacée par la dernière version utilisable.

Les mises à jour concernent le jeu complet (HTML, interface, physique et bibliothèques), sans remplacer le moteur Electron ni le lanceur Windows.

## Jouer entre potes

À l'accueil, choisissez **Jouer entre potes**. L'hôte crée une usine et donne son code aux invités. Jusqu'à quatre joueurs construisent dans une usine commune, avec budget partagé, curseurs nommés et repères **P**. La sauvegarde commune est distincte du solo et conservée chez l'hôte.

La coopération est une première version : les connexions entre réseaux différents et l'équilibrage des contrats restent à valider. Gardez la fenêtre de l'hôte visible pour que l'usine continue. Après un redémarrage de l'hôte, reprenez l'usine puis partagez son nouveau code.

## En cas de problème

La v19 ajoute un secours du bois : des états physiques invalides ou une surcharge prolongée peuvent déclencher le nettoyage des bûches et planches sur la carte, avec un message. Machines, minerais, budget et progression sont conservés. Un crash complet peut aussi déclencher cette récupération lorsque les diagnostics indiquent un risque lié au bois.

Pour récupérer les diagnostics, ouvrez **Paramètres → Sauvegarde → Enregistrer le journal**.

Les instructions, vérifications et limites détaillées accompagnent chaque [version du jeu](https://github.com/thimeobocquier/noyau-affame-telechargements/releases).
